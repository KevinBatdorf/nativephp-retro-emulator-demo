Bundled homebrew — credits & licenses
======================================

The games bundled with this demo are freely-licensed homebrew, included to
demonstrate the emulator. Credit and license for each below.

Bundled and playable from the home screen
-----------------------------------------

- NES — "Super Tilt Bro." by Sylvain Gadrat (sgadrat), WTFPL.
  https://github.com/sgadrat/super-tilt-bro
- SNES — "Space Rescue Squad" by Marcus Rowe (undisbeliever), music by
  KungFuFurby. Code zlib; resources source-available.
  https://github.com/undisbeliever/space-rescue-squad
- Game Boy — "Rex Runner GB" by The Void (etdv-thevoid), MIT.
  https://github.com/etdv-thevoid/rex-runner-gb
- Game Boy Color — "Tobu Tobu Girl Deluxe" by Tangram Games (Simon Larsen).
  Code MIT, assets CC-BY-4.0 (credit: "Tobu Tobu Girl by Tangram Games").
  https://tangramgames.dk/tobutobugirl/
- Genesis — "Miniplanets" by Javier Degirolmo (Sik), zlib.
  https://github.com/sikthehedgehog/miniplanets
- Game Boy Advance — "Blind Jump" by Evan Bowman, MIT.
  https://github.com/evanbowman/blind-jump-portable

Also bundled
------------

- "helloworld.sfc" — krom's SNES HelloWorld, used by the conformance screen.
- Shader: "crt-lottes" CRT scanline shader by Timothy Lottes, public domain
  (libretro slang-shaders, crt/crt-lottes.slangp).
